# Hooks

Hooks are React functions that let components reuse behavior or work with React features. Files here include filtering logic for categories, orders, and products.

Read a hook together with the component that uses it. Identify the inputs it receives, the values it returns, and whether it stores or derives data. A hook is not a separate screen; it helps a screen behave consistently.

**Practice:** find a component using one of the filter hooks. Follow how changing a filter affects the displayed list.
